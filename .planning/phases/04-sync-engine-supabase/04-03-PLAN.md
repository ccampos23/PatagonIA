  <action>
Create `SyncResult` sealed class:
- `Success(pushed: Int, pulled: Int, failed: Int)`
- `PartialSuccess(pushed: Int, pulled: Int, failed: Int, errors: List<SyncError>)`
- `Failure(error: Throwable)`

Create `CaptureSyncEngine` (injected with `CaptureDao`, `SupabaseCaptureDataSource`, `AuthRepository`):

**Push flow** (`suspend fun pushCaptures(): SyncResult`):
1. Query `CaptureDao.getPendingSyncCaptures()` (one-shot `.first()`).
2. For each capture by syncStatus:
   - `PENDING_INSERT` → call `SupabaseCaptureDataSource.insertCapture(dto)`. On success, `CaptureDao.markAsSynced(id, remoteId)`.
   - `PENDING_UPDATE` → call `SupabaseCaptureDataSource.updateCapture(dto)`. On success, mark SYNCED.
   - `PENDING_DELETE` → call `SupabaseCaptureDataSource.softDeleteCapture(remoteId)`. On success, mark SYNCED.
3. If any individual capture throws, catch the exception, call `CaptureDao.markAsSyncFailed(id)`, and continue with the rest (D-22).
4. Return aggregate `SyncResult`.

**Pull flow** (`suspend fun pullCaptures(isFreshInstall: Boolean): SyncResult`):
1. Get `userId` from `AuthRepository.getCurrentUser()`.
2. Call `SupabaseCaptureDataSource.fetchAllCaptures(userId)` (D-25 — all at once).
3. For each remote capture:
   - Check if a local capture with matching `remoteId` exists.
   - If `isFreshInstall` (no local captures): insert all remote captures as SYNCED (D-10).
   - If not fresh install and capture exists locally with PENDING_* status: SKIP (local-wins — D-09).
   - If not fresh install and capture exists locally with SYNCED status: update from remote (server has newer version).
   - If not fresh install and capture doesn't exist locally: insert as SYNCED.
4. Return aggregate `SyncResult`.

**Sharing toggle** (`suspend fun toggleSharingRemote(captureId: String, isShared: Boolean)`):
1. Get the capture's `remoteId` from DAO.
2. Call `SupabaseCaptureDataSource.updateSharingStatus(remoteId, isShared)` (D-16).

Create `SyncWorker` as a `@HiltWorker` `CoroutineWorker`:
- Inject `CaptureSyncEngine` via `@AssistedInject`.
- In `doWork()`:
  1. Call `captureSyncEngine.pushCaptures()`.
  2. Call `captureSyncEngine.pullCaptures(isFreshInstall)` where `isFreshInstall` is passed via `inputData`.
  3. On `SyncResult.Success` → return `Result.success()`.
  4. On `SyncResult.PartialSuccess` → return `Result.success()` (healthy data synced, failed ones quarantined — D-22).
  5. On `SyncResult.Failure`:
     - Read `runAttemptCount`. If < 3 → return `Result.retry()` (triggers exponential backoff — D-08).
     - If ≥ 3 → return `Result.failure()` with error data. Mark remaining as SYNC_FAILED. User must manually retry (D-23).
  6. Do NOT create any notification channels or show notifications (D-26).

Create `SyncOrchestrator` (injected with `WorkManager`):

**Immediate sync on data change** (`fun enqueueSync()`):
1. Build `Constraints` with `NetworkType.CONNECTED` (D-05 — any network). No charging requirement (D-06).
2. Build `OneTimeWorkRequest.Builder(SyncWorker::class.java)` with:
   - Constraints.
   - `setBackoffCriteria(BackoffPolicy.EXPONENTIAL, 15, TimeUnit.SECONDS)` — backoff starts at 15s, doubles up to 120s max (D-08).
   - `setInputData(workDataOf("is_fresh_install" to false))`.
3. Call `workManager.enqueueUniqueWork("capture_sync", ExistingWorkPolicy.KEEP, request)` — prevents duplicate sync jobs.

**Fresh install sync** (`fun enqueueFreshInstallSync()`):
1. Same as above but `setInputData(workDataOf("is_fresh_install" to true))` (D-10).
2. Use `ExistingWorkPolicy.REPLACE` since fresh install should always pull.

**Observe sync state** (`fun observeSyncState(): Flow<WorkInfo.State>`):
- Return `workManager.getWorkInfosForUniqueWorkFlow("capture_sync")` for UI observation.

Create `EnqueueSyncUseCase`:
- Wraps `SyncOrchestrator.enqueueSync()`.
- Called by `CaptureRepositoryImpl` after save/update/delete operations to trigger immediate sync (D-07).

Create `PullRemoteCapturesUseCase`:
- Wraps `SyncOrchestrator.enqueueFreshInstallSync()`.
- Called after first successful login to pull baseline data (D-10).

Wire `EnqueueSyncUseCase` into `CaptureRepositoryImpl`:
