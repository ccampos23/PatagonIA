# PataGOnIA Power Pitch

Deck web para el pitch formal de 5 minutos. Mantiene la estructura del guion original:

1. Hero
2. Problema
3. Solucion
4. Features
5. Demo
6. Mercado
7. Monetizacion
8. Tech Stack
9. Roadmap
10. Cierre

## Como presentarlo

Abrir `index.html` en un navegador y activar pantalla completa.

Controles:

- `Space`, flecha derecha o flecha abajo: avanzar.
- Flecha izquierda o flecha arriba: retroceder.
- Puntos superiores: saltar a una slide.

## Exportar a PDF

Opcion rapida: abrir en Chrome/Chromium, `Ctrl+P`, destino `Save to PDF`, orientacion landscape, backgrounds activados.

Si necesitan export automatico o PPTX, conviene migrar el contenido a Slidev despues de validar este deck.
